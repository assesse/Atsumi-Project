# Atsumi Next

Atsumi Next는 Windows에서 Hitomi 갤러리를 탐색하고 다운로드한 앨범을 관리하는 프로그램입니다.

검색부터 다운로드, 판본 비교, 중복 검토와 격리까지 한 앱에서 처리할 수 있습니다.

현재 버전은 **1.0.0**입니다.

## 다운로드

[GitHub Releases](https://github.com/assesse/Atsumi-Project/releases)에서 최신 버전을 받을 수 있습니다.

일반 사용자는 **`Atsumi-Setup.exe` 하나만 받으면 됩니다.** `latest.json`과 Source code 파일은 앱의 자동 업데이트 및 소스 공개를 위한 파일이므로 직접 받을 필요가 없습니다.

### Windows 보안 경고

Atsumi Next는 유료 Windows 코드 서명 인증서를 사용하지 않습니다. 따라서 처음 실행할 때 Windows에서 **알 수 없는 게시자** 또는 **Windows의 PC 보호** 경고를 표시할 수 있습니다.

이 저장소에서 직접 받은 파일인지 확인한 후 다음 순서로 실행할 수 있습니다.

1. **추가 정보**를 선택합니다.
2. 게시된 앱 이름과 파일명을 확인합니다.
3. **실행**을 선택합니다.

앱 내부 업데이트 파일은 별도의 업데이트 전용 서명으로 검증됩니다.

## 주요 기능

- 태그·작가·그룹·시리즈·캐릭터와 언어 조건을 이용한 갤러리 검색
- 즐겨찾기 작가를 기준으로 새 작품을 찾는 Auto Find
- 중단된 다운로드 재개와 다운로드 상태 관리
- 기존 앨범과 새 앨범의 판본·포함 페이지 비교
- 앨범 사이의 중복과 앨범 내부 중복 페이지 검토
- 중복 또는 오탐 판정에 따른 숨김·격리·복원 관리
- 시작 시 새 버전 확인과 설정에서 수동 업데이트
- 태그에 마우스를 올렸을 때 한국어 번역 표시
- 앨범 선택과 탐색을 위한 키보드 단축키

## 시작하기

1. Atsumi Next를 설치하고 실행합니다.
2. 설정에서 다운로드 폴더와 검색 조건을 확인합니다.
3. **Explore**에서 작품을 검색하거나 **Auto Find**로 즐겨찾기 작가의 작품을 찾습니다.
4. **Downloads**에서 진행 상태와 완료된 앨범을 관리합니다.
5. 중복이 발견되면 비교 화면에서 기존 앨범과 신규 앨범을 확인하고 처리 방법을 선택합니다.

## 데이터와 안전

- 설정, 다운로드 기록과 사용자의 중복 판정은 로컬에 저장됩니다.
- 검증이 끝나지 않은 다운로드를 완료된 앨범으로 취급하지 않습니다.
- 모호하거나 손상된 파일을 자동으로 덮어쓰거나 영구 삭제하지 않습니다.
- 격리하거나 탐색에서 제외한 앨범은 설정에서 확인하고 복원할 수 있습니다.
- 로컬 데이터베이스, 다운로드한 앨범과 개인 업데이트 키는 GitHub 저장소에 포함되지 않습니다.

## 업데이트

앱을 시작하면 새 버전이 있는지 확인하고, 업데이트가 발견되면 설치 여부를 묻습니다. 업데이트를 미뤘다면 설정에서 다시 수동으로 확인할 수 있습니다.

## 문제 제보

오류나 개선 제안은 [GitHub Issues](https://github.com/assesse/Atsumi-Project/issues)에 남겨주세요. 다음 내용을 함께 적으면 확인하기 쉽습니다.

- 사용 중인 Atsumi Next 버전
- 문제가 발생한 화면과 작업 순서
- 관련 갤러리 ID
- 가능하다면 오류 메시지 또는 화면 캡처
