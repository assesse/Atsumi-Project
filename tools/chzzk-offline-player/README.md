# CHZZK 원본 플레이어 로컬 테스트

기존 Atsumi 앱에 연결하지 않는 독립 테스트입니다. 인터넷·로그인·사용자 DB·녹화 파일을 사용하지 않습니다.

## 보기

Node.js가 설치된 PC에서 `start.cmd`를 실행한 뒤 브라우저에서 `http://127.0.0.1:18764`를 엽니다. 종료는 실행한 창에서 Ctrl+C입니다. 개발 앱의 1420 포트를 사용하지 않습니다.

생성된 `.runtime/chzzk-offline-player` 폴더에는 실행에 필요한 파일이 모두 있습니다. 이 폴더만 옮겨도 Node.js 외에 프로젝트·pnpm·설치·다운로드가 필요하지 않습니다. HTML을 file://로 직접 여는 대신 로컬 파일 서버로 제공하는 것은 브라우저 모듈·미디어 보안 규칙 때문이며 인터넷 서버에 연결하는 것이 아닙니다.

## 원본 보존 범위

- PC 플레이어 1.16.2의 JS 3개와 CSS 3개를 원본 바이트 그대로 사용합니다. 실행 전 SHA-256을 검사합니다.
- LIVE/VOD 화면과 LIVE 배지는 해시 고정된 원본 React 표현식에서 기계적으로 생성합니다. 문자열·SVG·조건·추출 위치는 manifest에 기록됩니다.
- 버튼·아이콘·CSS 속성을 다시 그리거나 기존 앱의 삭제·분석 오버레이 코드를 사용하지 않습니다.
- 원본 LIVE 앱이 광고 대기 상태를 해제할 때 적용하는 dimmed/poster 상태 연결은 동일하게 수행합니다. 이를 누락하면 원본의 검은 덮개가 영상 위에 남습니다.
- 넓게 보기는 원본 버튼의 change 이벤트를 테스트 프레임 폭에 연결합니다. 나머지 재생·음량·설정·배속·전체화면은 원본 SDK입니다.
- 라이브 방송 정보는 원본 `DJ` 상세 표현식을 원래의 `header_info` 포털에 연결합니다. 별도의 방송 정보 영역이 없는 독립 플레이어이므로 일반/넓은 화면 모두 같은 프로필 링·LIVE 배지·제목·채널명·시청자·업타임을 표시합니다. 마우스 표시/숨김은 원본 SDK와 스타일을 따릅니다.
- 요청에 따라 `player-adaptations.css`에서 ‘음소거 상태입니다’라는 떠 있는 안내만 숨깁니다. 실제 음소거 상태와 하단 음량 버튼·슬라이더는 바꾸지 않습니다.
- 라이브 채팅은 원본 `Nk` 외곽, `DS` 헤더/메뉴, `vD` 목록, `sC` 메시지/닉네임/배지, `Uv` 로그아웃 상태 입력창을 사용합니다. 기존 Atsumi 다시보기용 디자인을 사용하지 않습니다. 목록은 원본의 역방향 정렬·스크롤 CSS를 그대로 유지합니다.
- **녹화본 UI**만 입력창·후원/미션/전송 도구 영역을 채팅 검색으로 바꿉니다. 원본 입력창 스타일과 채팅 행을 유지하며, 별도 `replay-search.css`는 검색 영역에만 적용합니다. 라이브 모드는 바뀌지 않습니다.
- 검색창 하나로 본문 또는 닉네임에 입력한 문구가 포함된 채팅을 함께 찾습니다. 별도의 전체·본문·닉네임 선택과 재생 위치 상태줄은 표시하지 않습니다. 대소문자·앞뒤 공백·연속 공백·동등한 유니코드 표현을 정규화하고, 정규식이나 서버 검색은 사용하지 않습니다. ‘지우기’ 또는 Esc로 전체 채팅을 복원합니다. 검색해도 영상은 다시 로드하거나 멈추지 않습니다.
- 방송 정보와 60개 채팅은 명시적인 테스트 데이터입니다. 실제 방송·계정·저장 채팅을 읽지 않습니다. 온라인 계정·채팅 전송·프로필·후원·공유 플러그인 초기화는 연결하지 않으며, 관련 버튼은 로컬 검증 기록으로만 안내합니다.

## 로컬 전용 경계

원본 실행 프레임은 opaque sandbox이며 Atsumi IPC·계정 쿠키·부모 DOM에 접근하지 않습니다. 초기 문서부터 CSP로 외부 연결, 외부 폰트·스타일·이미지, 추가 프레임·워커를 거부합니다. 원본 SDK의 Nelo 전송 시도도 차단됩니다. 검증 기록에 요청 실패가 남을 수 있지만 재생 오류와 구분합니다.

원본 JS/CSS 6개는 바이트 그대로 보관합니다. 실제 화면은 원본 index CSS의 사용 자산 주소를 로컬 주소로 매핑한 `local-index.css`를 사용합니다. 원본 플레이어와 라이브 채팅의 색상·여백·크기·아이콘은 재디자인하지 않습니다. 요청에 따른 녹화본 검색 영역 및 음소거 안내 숨김은 별도 파일로 분리합니다. 사용하지 않는 전체 사이트 Pretendard import는 생략하며, 이 차이도 manifest에 기록합니다.

Sandoll Nemony2 원본 WOFF2 121개, 원본 UI 라이브러리 2개, 기본 프로필과 인증 아이콘을 로컬에 보관합니다. 원본의 WOFF 대체 주소나 플레이어·채팅 밖의 사용하지 않는 자산 참조는 남을 수 있으나, 그 외부 요청은 차단됩니다. 실행 중 누락 자산을 인터넷에서 가져오는 기능은 없습니다.

## 현재 테스트의 한계

- 영상은 로컬 30초 합성 파일입니다. 라이브 UI도 실제 생방송이나 DVR 수신이 아닙니다.
- 샵·클립·라디오·계정·시청자 정보 등 온라인 서비스는 연결하지 않습니다. 관련 원본 요소를 임의 삭제하지 않습니다.
- 기준은 보관된 1.16.2 버전입니다. 오늘의 웹 사이트 전체와 모든 상태의 픽셀 일치를 검증한 것은 아닙니다.
- 채팅 외형은 포함하지만 실시간 전송·녹화·마도·Atsumi 탭 통합은 이 테스트에 포함하지 않습니다. 후원 순위·고정 메시지·개별 구매 이모티콘·계정 프로필 등의 서버 데이터가 필요한 상태는 이번 샘플에 없습니다.
- 채팅 검색 대상은 현재 샘플 60개 전체입니다. 실제 녹화 보관함의 채팅 파일/DB 검색이나 검색 결과의 영상 시점 이동은 아직 연결하지 않았습니다.
- 공개 자산의 출처 보존은 재배포 허가를 뜻하지 않습니다. 이 묶음은 로컬 검증용입니다.

## 재현 가능한 검사

프로젝트에서 `node --test tools/chzzk-offline-player/proof.test.mjs`로 원본 해시, HTML 보존, CSP, 파일 접근 제한과 Range 재생 응답을 검사합니다. `node tools/chzzk-offline-player/build.mjs`는 기존 로컬 원본만 읽어 테스트 묶음을 재생성하며 네트워크에서 누락 자산을 가져오지 않습니다.

최초 자산 준비용 `acquire-surfaces.mjs`만 원본 배포물에 기재된 네이버 공개 CDN 주소를 읽습니다. 이는 실행 서버와 분리되어 있으며 생성한 독립 폴더에는 포함하지 않습니다. 로그인·쿠키·사용자 DB를 사용하지 않습니다.
