## 변경 계약

- 최종 병합, 검증 완료 원본 정리, 실시간 구간 병합을 하나의 제한된 작업자에서 번갈아 선택한다. 실시간 구간 병합도 채널 사이에 순환한다.
- 종료된 녹화는 작은 구간 파일을 추가 생성하느라 대기하지 않고 최종 병합으로 간다.
- 이미 검증된 구간 파일이 전체를 덮으면 재사용한다. 일부만 덮으면 **원본 전체**로 최종 병합한다. 구간 파일과 원본을 섞지 않는다.
- 실제 MP4는 구간 remux 시 영상 time base가 `1/6000`에서 `1/12000`으로, 초기화 데이터 표현도 달라졌다. 일부 구간 파일과 원본을 섞는 방식은 엄격한 형식 검증에서 거부됨을 실제 파일로 확인했다. 형식 검증을 느슨하게 만드는 대신 입력을 통일했다.
- 형식·시간축 사전 검사를 대용량 원본 해시 계산보다 먼저 한다. 읽기 전용 미디어 검사에서 시간 초과가 발생했을 때만 90초 한도로 한 번 재시도한다. 실제 손상, 취소, 병합 출력 작업은 자동 재시도 대상으로 취급하지 않는다.
- 병합은 재인코딩하지 않는다. 결과 전체 영상·음성 디코딩, 길이, 형식, 원본과 결과의 해시 검증 및 정리 근거 저장 후에만 원본 조각을 제거한다. 채팅, 시청자 수, 프로필, 오류 및 시간표는 유지한다.
- 전체 재생 검증은 낮은 프로세스 우선순위와 논리 CPU의 1/4 이하(최대 4개) 디코더 스레드로 제한한다. 33초 1080p 실제 테스트 파일에서 단일 스레드 약 7.80초, 4개 약 2.74초를 관측했다. 검증용 null 출력에도 원본 시간 단위를 사용하고 프레임을 추가/제거하지 않는다. 기존 FPS 단위 반올림에서만 발생하던 null muxer 중복 DTS 경고가 같은 입력에서 사라졌으며, 원본·최종 영상 파일에는 이 검증 설정이 반영되지 않는다. [FFmpeg 공식 옵션 설명](https://ffmpeg.org/ffmpeg.html#Advanced-options)
- 최종 병합과 원본 정리가 완료되면 중간 구간 병합의 불완전한 요약 때문에 매 실행 시 원본 검사를 되풀이하지 않는다.

## 화질

화질 선택 완료는 메뉴 문구가 아니라 실제 디코딩된 영상 크기로 확인한다. 녹화 시작은 전환 중에 진입하지 않는다. 이미 원본을 녹화 중이면 이번 정책이 추가 화질 변경을 일으키지 않는다. 별도 방송 다운로드, 중복 스트림, 권한 우회, 로그인 변경을 하지 않는다. 공식 플레이어 내부 참조가 사라지거나 모호해지면 기본 재생을 유지한다.

실제 방송의 자발적인 소스·코덱 변경까지 하나의 파일로 무중단 승계하는 기능은 이 변경의 범위가 아니다. 예전에 이미 누락된 영상도 복원하지 않는다.
