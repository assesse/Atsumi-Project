# 개발 앱 정상 종료

앱 화면을 조작할 수 없어도 저장된 로컬 제어 주소를 통해 정상 종료를 요청할 수 있습니다.

```powershell
& .\tools\request_app_shutdown.ps1
```

기본값은 진행 중인 다운로드·녹화 등의 작업이 있으면 종료를 거부합니다. 해당 작업도 기존 앱의 종료 절차로 정리하고 종료하려면 명시적으로 지정합니다.

```powershell
& .\tools\request_app_shutdown.ps1 -DrainWork
```

앱의 네이티브 시작 취소 또는 작업 상태 확인·정리 절차를 그대로 호출합니다. 강제 종료, 데이터 삭제, 로그인 초기화는 수행하지 않습니다. 앱이 실행 중이지 않으면 새로 실행하지 않습니다. 요청이 승인된 뒤에도 정리가 끝나지 않았으면 `draining`을 반환합니다.

제어 주소는 `%APPDATA%\local.atsumi.next\diagnostics\control-endpoint.json`에 있습니다. IPv4 루프백, 실행마다 바뀌는 인증 토큰, 현재 PID와 UI epoch를 확인하며 브라우저 Origin 요청은 거부합니다. 토큰을 로그나 대화에 붙이지 마세요. 기본 대상은 이 작업 공간의 debug 실행 파일이며 다른 설치를 대상으로 할 때만 `-ExpectedExecutable`을 명시합니다.

실행별 `control-endpoint-<PID>.json`도 함께 저장합니다. 다른 실행이 최신 파일을 덮더라도 실행 중인 정확한 대상 파일을 찾으며, 일치하는 앱이 여러 개면 `-TargetProcessId`로 하나를 지정해야 합니다. 실행 중인 앱의 인증된 주소를 찾지 못하면 오류를 반환합니다. 이를 앱이 꺼졌다는 의미로 처리하지 않습니다.

종료 코드는 0(종료 완료 또는 실행 중 아님), 2(작업 등으로 거부), 3(승인됐으나 대기 시간 내 정리 중)입니다. 인증·통신·대상 검증 실패는 오류로 처리합니다. `-WaitSeconds`의 기본값은 45초입니다.
