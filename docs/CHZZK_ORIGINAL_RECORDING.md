# CHZZK 원본 수신 녹화

2026-09-14. 기존 2849 작업공간에서 구현하며, 이전 녹화와 오프라인 플레이어 체크포인트는 수정하지 않는다.

## 확인된 결함

실제 공개 방송의 일반 화질 수신에서 AVC/AAC가 함께 든 fMP4 SourceBuffer와 음수 `timestampOffset`을 관측했다. 기존 관측기는 offset=0만 허용해 정상 수신을 `timeline_changed`로 차단했다. 이후 재생 출력 재인코딩으로 자동 전환되어 공식 플레이어의 1.03배 자동 지연 보정에도 녹화가 중단될 수 있었다.

추가로 실제 일반/그리드 입력에서 다음 호환성 결함을 확인했다.

- 빈 `stss` 표가 있는 정상 초기화 헤더를 거절했다. 빈 표만 허용하며 채워진/중복 표 및 암호화 트랙은 여전히 거절한다.
- 일반 화질 AAC의 48 kHz ±1틱, 그리드 영상의 6 kHz -4틱 같은 경계 차이를 누락/중복으로 오인했다. 보정은 **1 ms 이하이면서 해당 샘플 길이의 1/16 이하**로 제한한다. 첫 샘플의 컨테이너 시작/길이만 조정해 끝 시각, 후속 샘플 시각, 압축 데이터는 유지하며 누적 시프트를 만들지 않는다.
- `readyState`가 낮아지는 일시 버퍼링을 MediaSource 교체로 오인했다. 재생 준비 상태와 실제 소스 동일성을 분리한다.
- 종료 순간의 정상 A/V 패킷 끝 차이도 오류였다. 최종 구간에 한해 한 패킷/프레임 미만이면서 50 ms 미만의 음성 끝 차이는 실제 수신 패킷 그대로 보존한다. 긴 누락은 거절하며 음성 생성이나 영상 삭제를 하지 않는다.

## 이번 구현의 계약

- 공식 페이지가 이미 수신해 MSE에 공급하는 압축 데이터만 저장한다. 별도 방송 다운로드, 추가 로그인, DRM 우회, 재인코딩을 하지 않는다.
- 녹화를 시작할 수 없으면 원본 수신 상태와 이유를 알린다. 출력 재녹화로 자동 전환하지 않는다.
- 입력 데이터와 원래 append 호출 결과를 바꾸지 않는다. 저장 전송은 크기가 제한된 비동기 큐로 처리한다.
- finite timestampOffset을 허용한다. 화면의 시각과 압축 영상의 시각을 혼동하지 않는다: `원본 PTS = 화면 currentTime - 해당 영상 SourceBuffer의 timestampOffset`.
- 녹화의 배속·음량은 원본에 적용하지 않는다. 시청 pause/seek 자체는 녹화 종료 사유가 아니다. 소스 교체·지원하지 않는 코덱·손상·저장 실패는 구체적인 사유로 표시한다.
- 시청 pause로 공식 수신기가 수신을 멈추면 녹화는 수신 대기로 표시한다. 이를 숨겨서 계속 저장 중인 것처럼 표시하지 않는다. 장시간 pause/seek와 수신까지 완전히 독립시키는 구조는 별도 검토 대상으로 둔다.
- 원본 조각은 기존 native 검증·세그먼트 저널·종료 병합 경로를 사용한다. 이미 확정된 조각과 과거 녹화는 유지한다. 버퍼에만 있는 미확정 데이터를 저장 완료로 표시하지 않는다.
- 녹화 시작 이후 도착하는 원본 중 독립 디코딩 가능한 첫 키프레임부터 저장한다. 이미 재생 버퍼에 들어온 과거 GOP를 소급 저장하는 기능은 이번 범위가 아니다.
- 지원 여부와 중단 사유에는 코덱 종류·시간 오프셋·수신량 등 한정된 진단만 남긴다. 쿠키, 토큰, 미디어 URL, 원시 페이지 데이터는 진단에 남기지 않는다.
