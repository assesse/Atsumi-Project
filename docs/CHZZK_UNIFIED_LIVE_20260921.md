# 라이브 진입 통합

## 사용자 흐름

- 실시간 시청은 CHZZK의 **라이브** 탭 한 곳에서만 시작한다. 자동 녹화 탭의 ‘실시간 보기’ 버튼은 제거한다.
- **내 채널**에 즐겨찾기와 자동 녹화 예약 채널을 채널 ID 기준으로 합쳐 표시한다. 두 목록에 있는 채널도 한 행만 표시한다.
- 일반모드는 한 채널, 마도모드는 최대 네 채널을 선택하고 시청을 시작한다. URL 직접 입력도 동일한 연결 절차를 이용한다.
- 별표는 즐겨찾기만 변경한다. 예약 등록·해제·녹화 중지는 자동 녹화 탭의 기존 기능으로 남긴다.
- 시청 종료/탭 이동/배치 변경은 녹화 중지가 아니다. 계정·그리드 변경은 여전히 진행 중 녹화를 보호하기 위해 제한한다.

### 2026-09-22 진입과 채널 선택

- CHZZK는 마지막으로 선택한 라이브·녹화 목록·자동 녹화 탭을 다음 실행에도 복원한다. 명시적인 이동 요청을 우선하며, 저장값이 없거나 잘못되었으면 라이브를 표시한다. 저장소를 사용할 수 없어도 탐색은 계속 동작한다.
- 연결 전 라이브에서는 내 채널 선택과 주소 입력을 본문에 표시한다. 진입·재진입·시청 종료만으로 설정 팝업을 열거나 포커스를 옮기지 않는다.
- ‘내 채널’을 눌러 연 연결 패널은 비모달이다. 패널 안에서 설정하면서 사이드바와 가려지지 않은 영상·채팅을 조작할 수 있으며 Tab 이동을 가두지 않는다. 닫을 때 이미 배경으로 옮긴 포커스를 되돌리지 않는다.
- 늦게 도착한 최초 시청 상태가 입력 중인 초안을 지우거나 명시적으로 연 패널을 닫지 않는다. 시청 시작이 성공하면 연결 폼을 닫는다.
- 화면 저장 등 확인창과 프라이버시 가림은 기존 차단 동작을 유지한다. 비모달 패널 밖의 단축키는 사용할 수 있지만 입력칸에서는 실행하지 않는다.
- 저장하는 새 설정은 탭 식별자뿐이다. 자동 녹화 작업자·예약 설정·수신기 수명은 변경하지 않는다.

## 구현 경계

`StreamingWorkspace` → `MadoWorkspace(unifiedLive)` → `configure_multiview`

일반·마도 모두 같은 연결 명령을 사용한다. 영상 수신기는 기존 `chzzk-auto-*` 인프라를 공유하며 이름의 auto는 내부 식별자이지 예약 녹화 설정이 아니다. 스케줄러와 라이브의 생성 경합은 별도 수신기 생성 잠금으로 직렬화한다.

채널이 이미 수신 중이면 동일한 네이티브 컨트롤러를 붙인다. 새 페이지로 이동하거나 녹화 ID를 교체하지 않는다. 영상과 녹화 수명은 화면 배치 수명과 분리한다. 배치 해제 시 영상은 음소거된 화면 밖 렌더러로 돌아가며, 시청/녹화/스케줄러 모두 사용하지 않을 때만 정리한다. 채팅 전용 창에는 미디어 수신·녹화 브리지가 없다.

배치 교체·F5·늦게 도착하는 화면 좌표 요청에는 epoch/revision 검사를 적용한다. 부분 연결 실패 시 이미 진행 중인 녹화를 닫지 않고 실패한 배치만 해제한다. 그리드 연결은 삭제된 단일 시청창 대신 현재 수신기들의 공용 프로필에 연결한다.

즐겨찾기는 `chzzk-live-favorites.json`에 원자적으로 저장한다. 자동 녹화 설정 파일과 독립적이며, 손상된 즐겨찾기 파일은 자동 덮어쓰지 않는다. 네트워크 오류로 목록을 못 읽어도 주소 직접 입력은 사용할 수 있다.

## 한계 및 검증

공식 플레이어의 영상 수신과 일시정지/되감기를 완전히 분리하는 작업은 이번 변경에 포함하지 않는다. 장시간 일시정지에 따른 기존 수신 제한은 남아 있다. 동일 방송의 이중 영상 연결을 없애는 변경이지 별도 독립 수신 엔진을 만든 것은 아니다.

회귀 검증은 즐겨찾기 지속성·예약 독립성, 단일 진입, 두 녹화와 일반 방송의 혼합 배치, URL 중복 제거, 시청 종료/재부착 시 수신기와 녹화 보존, 오래된 화면 요청 차단을 포함한다. 별도 로컬 WebView2 연속성 검증은 합성 영상만 사용하며 실사용 계정·녹화 파일을 변경하지 않는다.
