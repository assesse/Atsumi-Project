# 스크린샷 즉시 촬영

## 변경

- 플레이어 버튼/S 키에서 첫 `await` 전에 `drawImage`로 프레임을 확보한다. 네이티브 승인이나 PNG 저장을 기다리는 동안 영상이 진행되어도 그 프레임을 다시 촬영하지 않는다.
- 네이티브는 정확한 공식 채널 URL·문서 세대·프로필 상태를 확인하고 일회용 저장 nonce를 반환한다. 저장 경로는 앱 설정만 사용하며 원격 페이지에서 지정할 수 없다.
- 스크린샷 시작 요청부터 PNG 저장까지 녹화 데이터와 별도인 2칸 대기열을 사용한다. 최대 128 KiB 조각 두 개만 전송 중일 수 있고 두 ACK 후 다음 묶음을 보낸다.
- 신뢰된 메인 화면의 S 키도 단일·마도·자동 수신기에서 같은 저장 경로를 즉시 호출한다. 이 경우 프레임은 플레이어에 명령이 도착한 시점에 확보한다. 2초 상태 폴링과 확인 팝업을 거치지 않는다.
- 진행/완료/실패는 플레이어 위의 비모달 알림으로만 표시한다. 영상 일시정지·재수신·크기 변경은 하지 않는다.

## 유지하는 제한

한 화면당 한 작업, 최대 4096px/16 MiPixels/PNG 16 MiB, 네이티브 만료 20초, 페이지 세대·채널 일치, 완전한 PNG 검증, 고유 파일 생성 및 저장 완료 확인은 유지한다. 채널 이동·문서 이탈·네이티브 거부는 해당 스크린샷만 취소하며 녹화를 중단하지 않는다.

## 검증 범위

회귀 테스트에서 IPC 응답 전 촬영, 늦은 승인에도 프레임 유지, 연속 입력 억제, 최대 두 조각 전송, 승인 거부·채널 변경·페이지 이탈·용량 초과·비신뢰 입력을 확인한다. 디스크 합성 벤치마크 수치는 실제 라이브 플레이어의 클릭부터 완료까지 시간을 보장하는 값이 아니다.
