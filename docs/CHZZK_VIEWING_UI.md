# CHZZK 시청·녹화 보관함 UI

2026-09-13 적용 범위. 기존 녹화 파일과 계정 세션은 변경하지 않는다.

## 연결과 마도

- 주소 입력 위의 방송 번호는 시각적으로 숨기고 접근성 이름으로 유지한다.
- 배치는 `4화면4챗`, `1화면4챗`으로 표기한다.
- 도움말은 아래로 펼쳐지며 높이·투명도가 전환된다. 닫힌 설명은 포커스와 접근성 트리에서 제외하고, 동작 줄이기 설정에서는 애니메이션을 생략한다.
- 영상 위의 Atsumi 번호·채널명 행은 제거한다. 선택·음성·상태 제어는 연결된 채팅 헤더에 둔다.
- 방송 정보는 CHZZK의 원래 넓게 보기 버튼을 통해 원본 헤더 컴포넌트를 활성화한다. 아바타·제목·채널·시청자·업타임을 별도로 복제하거나 추측하지 않는다. 기존에 사용자가 넓게 본 상태는 임의로 되돌리지 않는다.

## 팝업과 방송 유지

기존 방식은 팝업 위쪽을 기준으로 네이티브 화면 전체 폭을 잘라냈다. 이제 방송 뷰포트와 스크롤 클립은 그대로 유지하고, 신뢰된 Atsumi 팝업의 실제 사각형과 그림자 여유 8px만 화면 영역에서 뺀다.

- 여러 방송을 가로질러도 각 화면과 겹치는 부분만 제외한다.
- 도움말 전개·줄바꿈으로 팝업 크기가 바뀌면 그 사각형을 다시 관측한다.
- 팝업 중에는 배경 입력을 막되 영상 재생을 중지하거나 창 크기를 바꾸지 않는다.
- 알 수 없는 팝업, 측정 실패, 프라이버시 상태에서는 기존의 전체 가림을 유지한다.
- 네이티브 복합 영역은 한 번에 적용하고 정확히 일치하는지 검증한다. 종료·프라이버시 전환 후 오래된 비동기 갱신으로 화면이 다시 나타나지 않아야 한다.

## 녹화 보관함

목표는 저장 영상을 찾아 재생하고, 중단·병합·채팅 누락이 있는 기록만 쉽게 확인하는 것이다.

- 진행 중인 녹화를 위에 분리한다.
- 저장 영상은 제목, 녹화일, 길이, 용량, 상태를 담은 카드 그리드로 표시한다.
- 전체 / 재생 가능 / 확인 필요 필터와 제목·채널 검색을 제공한다.
- 카드 24개부터 시작하여 더 보기로 늘린다. 주기적 상태 갱신은 사용자가 펼친 개수와 선택을 초기화하지 않는다.
- 선택한 녹화의 재생·외부 플레이어·폴더 동작과 오류를 상세 패널에 둔다. 작은 창에서는 세로로 배치한다.
- 조각 파일은 상세 안에 기본 접힘으로 유지한다. 병합 검증, 정리 실패, 누락 경고를 숨기거나 완료로 바꾸지 않는다.
- 목록 진입만으로 영상·썸네일을 모두 열지 않는다. 메타데이터만 이용한다.
- 프라이버시 모드에서는 제목·경로·파일명을 숨기고 검색어를 비운다.

## 다시보기와 시청자 기록

채팅 시간의 적용이 성공하면 조정 패널을 닫는다. 실패하면 입력과 재시도 동작을 유지한다. 이전 녹화 세션의 늦은 응답은 현재 세션에 적용하지 않는다.

시청자 수는 새 녹화 중 공개 상태 API를 10초마다 조회한다. 이는 원본 화면의 약 30초 갱신값을 2초마다 반복 읽던 방식과 다르다. 영상 스트림을 추가로 받지 않는다. 실패·비공개·다른 방송의 값은 누락으로 남기며, 서버 집계 자체가 매번 달라진다고 보장하지 않는다. 상세 계약은 `CHZZK_CHAT_ENHANCEMENTS.md`와 `CHZZK_CAPTURE_CLOCKS.md`에 기록한다.
