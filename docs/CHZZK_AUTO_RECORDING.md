# CHZZK 자동 녹화 · 즉시 녹화

## 사용

- CHZZK → **자동 녹화**에서 채널 주소/ID를 등록한다. 최대 32채널이며 목록과 켜짐 상태는 앱 재시작 후 유지된다.
- 앱 실행 중(트레이 포함) 공개 방송 상태를 약 30초마다 확인한다. 이미 방송 중인 채널을 등록해도 시작 대상이다. 앱 종료/PC 절전 중에는 탐색하지 않으며, PC를 깨우거나 자동 실행 설정을 변경하지 않는다.
- 원래 플레이어의 녹화 버튼은 즉시 시작/중지한다. 권한 동의 체크박스나 시작·중지 확인창은 없다. 파일 마무리는 백그라운드에서 진행한다.
- 실제 시작·마무리 때 우측 하단에 짧게 알린다. 라이브에서는 원래 웹 화면 안에 비모달 알림을 표시하여 화면을 숨기거나, 재생을 멈추거나, 입력을 막지 않는다. 다른 탭에서는 앱의 기존 알림을 사용한다.
- **녹화 중지**는 현재 회차를 건너뛴다. 같은 방송을 즉시 자동 재녹화하지 않는다. 다시 켜면 현재 회차도 재시도한다.
- **실시간 보기**는 녹화 중인 채널에 표시된다. 별도 방송 연결 없이 현재 수신 화면을 기존 라이브 UI에 연결한다. 채팅·공식 음량·배속·따라잡기·스크린샷·시청 설정·녹화 버튼을 그대로 사용한다. **녹화만 계속**은 플레이어의 공통 버튼이며, 음소거하고 화면만 닫아 영상·채팅 녹화를 유지한다. **녹화 중지**와는 다르다.
- **녹화 준비**는 아직 저장 전이다. **시도 중지**는 준비/재시도를 취소하며, 실제 **녹화 중**과 구분한다. 시작하지 못했다면 채널 아래 **최근 저장 미시작**에서 시각과 이유를 확인한다. 중지·방송 종료·앱 재시작만으로는 지우지 않지만, 이후 실제 녹화가 시작되면 이전 실패 기록을 화면과 저장 설정에서 제거한다. 준비/재시도 상태만으로 지우지는 않는다.
- **꺼짐/해제**는 자동으로 시작한 녹화를 마무리한다. 별도로 수동 시작한 녹화는 건드리지 않는다. 등록 해제는 저장된 영상·채팅을 삭제하지 않는다.
- 로그인·그리드 연결이 필요한 채널은 라이브에서 미리 연결한다. 기존에 선택한 그리드 자동 연결만 복원한다. 인증·구독·설치 안내를 임의 클릭하지 않는다.

## 2026-09-16 라이브 화면 재사용 · 진행 중 구간 병합

- 자동 녹화 목록의 **실시간 보기**는 기존 **라이브** 컴포넌트와 플레이어 제어 코드를 사용한다. 녹화 수신 WebView의 영상 전용 레이아웃만 해제하여 원래 채팅과 입력창을 복원한다. 페이지 재이동·영상 요소 교체·별도 영상/채팅 수신은 없다. 스크린샷 승인은 같은 확인창을 사용하되 해당 세션의 일회용 요청만 승인한다.
- 화면·음량·녹화 명령을 현재 시청 ID와 원래 문서 세대에 연결한다. 다른 일반 라이브나 마도 세션의 제어 명령을 실행하지 않는다. 녹화가 중지되어도 사용자가 보는 화면은 유지하며, 사용자가 별도로 시작한 새 녹화를 이전 자동 작업의 종료 처리로 닫지 않는다. 자동 작업이 끝난 수신기는 시청/녹화/확인 요청이 모두 끝난 뒤 회수한다.
- 시청 중에는 자동 재생 타이머가 사용자의 일시정지를 취소하지 않는다. 크기 변경으로 공식 음소거 선택을 덮어쓰지 않는다. 백그라운드 복귀 시에는 소리 없이 기존 수신을 계속한다. 방송 주소·그리드 재연결은 현재 세션에서 금지하며, 시청을 닫은 뒤 일반 라이브에서 변경하도록 안내한다.
- 개발 앱의 React StrictMode가 효과를 정리했다가 다시 붙일 때 시청 권한까지 해제하던 결함을 수정했다. 같은 시청의 즉시 재연결은 해제를 취소하고, 실제 탭 이동·닫기·다른 시청 ID로 변경될 때만 해당 권한을 반납한다. 공통 라이브의 상태 확인 실패 안내를 사용하며, 프라이버시 모드와 오류 안내를 구분한다.
- **이 빌드에서 새로 시작한 녹화부터** 확정 조각이 약 **3분 또는 48 MiB**에 도달하면 백그라운드에서 무손실 구간 병합과 재생 검증을 수행한다. 조각 경계·30초 이내 작업 확인 주기·기존 병합 작업 때문에 실제 준비 시점은 달라질 수 있다. 기존 녹화를 일괄 재병합하거나 서로 다른 녹화 ID를 자동 합치지 않는다.
- 녹화 보관함에서는 구간/최종 병합 여부와 관계없이 **앱에서 다시보기**를 사용한다. 동일한 원본 플레이어의 조작부·전체 시간축·저장 채팅으로 재생하며, 별도 간이 플레이어는 사용하지 않는다. 마지막 구간에 도착하면 새 완료 구간을 확인하고 녹화 중이면 15초 간격으로 다시 확인한다. 앞부분을 보는 중에는 자동 갱신하지 않으며 영상 위의 **새로고침**으로 수동 확인할 수 있다. 영상 위에는 현재 재생 가능 시각만 간결하게 안내한다. 아직 확정되지 않은 꼬리 구간은 재생하지 않는다.
- 녹화 종료 시 남은 짧은 구간을 먼저 확정하고, 이미 만든 구간을 입력으로 최종 MP4/WebM을 만든다. 최종 파일 생성·전체 재생 검증에 필요한 디스크 읽기/쓰기는 남는다. 재인코딩이나 누락 프레임·채팅 복구를 하는 기능은 아니다. 구간 간 전환은 로컬 파일 전환이므로 아주 짧은 재생 틈이 생길 수 있다.

### 파일·복구 보호

- `progressive.json`에 완료 범위와 순서를 원자적으로 기록한다. 진행 중인 꼬리는 계속 추가할 수 있지만 이미 확정한 앞부분의 변경은 거부한다. 메타데이터 쓰기 직전에 종료돼도 완료 목록을 읽어 같은 범위를 다시 만들지 않는다. 기록이 손상되면 원본을 보존하고 재시도 안내를 표시한다.
- 구간마다 원본 SHA-256, 출력/시간표 검증 근거를 보존한다. 최종 파일 생성 전에 구간과 원본을 다시 대조하고, 최종 파일의 전체 재생 검증·영구 기록이 끝난 뒤에만 증명된 원본 조각과 임시 구간 영상/시간표를 정리한다. 실패·취소·디스크 부족에서는 성공으로 표시하거나 원본을 제거하지 않는다. 채팅·녹화 메타데이터·최종 시간표·검증 기록은 유지한다.
- 녹화 중에는 원본과 병합 구간이 함께 있으므로 영상 용량의 약 2배, 최종 파일 작성 중에는 일시적으로 약 3배의 공간이 필요할 수 있다. 최종 정리 후에는 최종 영상과 작은 부가 기록이 남는다. 사용 중인 파일의 정리가 차단되면 기존 재시도 경로를 이용한다.
- 다시보기는 완료 구간의 읽기 전용 핸들과 채팅/시간표 스냅샷을 사용한다. 원본에 새 채팅이 추가되거나 최종 파일로 정리돼도 이미 열린 재생은 유효하다. 진행 중 구간용 임시 채팅 인덱스/스냅샷은 닫을 때 정리하고, 최종 저장본의 기존 인덱스 캐시는 유지한다.
- 병합은 기존의 낮은 우선순위 단일 워커를 공유한다. 앱 종료 시 취소할 수 있으며 이후 확정되지 않은 작업을 재시도한다. 앱 종료/절전 사이의 녹화 공백이나 서로 다른 회차의 중복 여부는 추측해서 복구·제거하지 않는다.

### 수신과 자동 시작

- Rust에서 메타데이터 확인과 녹화 제어를 별도 워커로 수행한다. 프런트엔드 탭 전환, 새로고침, 최소화에 의존하지 않는다. 네트워크 요청 실패는 방송 종료로 간주하지 않는다.
- 연속 2번 종료 상태를 확인하면 녹화를 마무리한다. 방송 회차는 `liveId`(없으면 방송 시작 시각)로 구분한다. 회차를 확인할 수 없거나 정보가 오래되면 새 녹화를 시작하지 않는다.
- 이미 같은 방송이 열려 있으면 기존 수신을 재사용한다. 그렇지 않으면 음소거된 녹화 전용 공식 플레이어를 생성한다. 이 전용 창은 부모 창의 클라이언트 영역 밖 `(-2560, 0)`에 고정한 `1280×720` 웹뷰다. 사용자에게는 보이지 않지만 WebView2의 렌더러는 활성 상태로 유지한다. 일반 시청/Mado 창의 배치·포커스·숨김 정책은 변경하지 않는다. 별도 HLS 다운로드나 화면/소리 재녹화는 하지 않고 기존 원본 데이터·채팅·병합 경로를 이용한다.
- 수동 녹화까지 합쳐 최대 4개, 자동 준비 화면도 최대 4개로 제한한다. 초과 채널은 대기한다. 실패한 연결은 60~120초 뒤 재시도한다.
- 배속과 무관하게 수신 원본을 저장한다. 플레이어 수신이 멈추는 상황의 한계는 기존 원본 저장 방식과 동일하다.
- 자동 녹화 **이후**에는 목록의 **실시간 보기**를 이용한다. 자동 수신 WebView의 위치·표시·음소거만 바꾸며 같은 녹화 ID·문서 세대·영상 및 채팅 저장 경로를 유지한다. 기존 라이브/마도 수신을 빌려 녹화 중이었다면 그 화면으로 돌아가며 재연결/마도 재구성을 호출하지 않는다. 주소를 직접 입력해 별도로 시청을 여는 동작은 이 재사용 경로와 다르다.
- 시청 시작은 클릭한 채널/녹화 ID를 대조하고, 이후 권한은 같은 수신기와 문서 세대에 묶인 임시 lease로 관리한다. 이미 끝난 녹화의 오래된 열기 요청은 거부한다. 늦은 표시·음소거·닫기 응답은 시청 ID, 문서 세대, viewport epoch/sequence/revision으로 차단한다. 프라이버시·탭 전환·main 새로고침은 시청만 해제하며 자동녹화 등록/건너뛰기 상태를 변경하지 않는다. 백그라운드 복귀도 렌더러를 계속 숨기는 대신 기존 화면 밖 1280×720 영역을 사용한다.

## 데이터와 보호

- 설정은 앱 데이터의 `chzzk-auto-record.json`에 원자적으로 기록한다. 잘못된 설정은 덮어쓰지 않고 자동 시작을 중지한다.

- 채널·문서 세대·일회용 시작 토큰·실제 녹화 ID를 확인한다. 사용자가 이어서 시작한 새 녹화를 이전 자동 작업으로 오인하여 중지하지 않는다.
- 앱 종료/업데이트의 기존 작업 관리에 자동 녹화를 포함한다. 종료 시 전체 녹화의 마지막 영상과 채팅을 먼저 마무리한다.
- 웹 페이지에는 파일 경로, 계정 쿠키, 임의 Tauri 명령 권한을 추가로 제공하지 않는다. 녹화에 대한 앱 확인창 제거는 서비스 측 접근 제한을 해제하는 기능이 아니다.
