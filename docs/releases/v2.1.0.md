# Atsumi v2.1.0

탐색·설정·다운로드 상태 표시를 다듬고, CHZZK 시청과 녹화 재생의 안정성을 보강했습니다.

- 검색 언어 전환과 탐색 상태 복원, 카드 다중 선택·우클릭 메뉴, 작업 큐와 진행 표시를 개선했습니다.
- 설정 자동 저장과 기능별 배치를 정리하고, 처음 사용하는 기능의 단계별 안내를 추가했습니다.
- 내 즐겨찾기를 앨범·페이지 중심으로 단순화했습니다. 기존 즐겨찾기와 분류 정보는 보존합니다.
- 커뮤니티에 내 후기 조회와 작품 미리보기, 인기순·최신순·낮은 평점순 정렬을 추가했습니다.
- CHZZK 채널 선택과 시청 화면, 자동녹화 상태 표시, 녹화 목록·재생·채팅 표시를 개선했습니다.
- 화면 멈춤과 검색·다운로드·녹화 문제를 추적할 수 있도록 용량 제한이 있는 로컬 진단 기록을 보강했습니다. 새 진단 기록을 외부로 자동 전송하지 않습니다.
- 개발 앱의 실행·복구 경로를 정리하고, 무설치 실행 시 설치형 업데이트가 잘못 실행되지 않도록 보호했습니다.

기존 다운로드·녹화·설정은 유지합니다. 업데이트 전 진행 중인 작업을 마치고 앱을 정상 종료해 주세요. 업데이트 후 같은 데이터 폴더를 이전 버전의 앱으로 열지 마세요.

Windows 게시자 서명(Authenticode)은 없는 배포입니다. 앱 내부 업데이트는 기존 Atsumi 업데이트 키로 설치 파일을 검증합니다.

설치는 `Atsumi-Setup.exe`를 사용하세요. 녹화 병합 도구는 설치 파일에 포함되어 있습니다.
