# Atsumi 2.3.3

## 다운로드

- **Atsumi-Portable.zip**: 압축을 모두 풀고 Start-Atsumi.cmd 실행.
- **Atsumi-Setup.exe**: 설치형.
- 기존 설정·로그인·다운로드·녹화 데이터는 초기화하지 않습니다.

## 이번 버전

현재 소스를 배포하는 릴리즈입니다. 배포 스크립트와 오래된 테스트 기대값만 수정했으며, 이번 배포 수정 때문에 앱 기능이나 UI를 바꾸지 않았습니다.

- X 공식 웹 피드·다중 탭 프리뷰·계정 전환·마음에 들어요·북마크·로컬 저장소.
- X 게시물·로드된 답글 보관, 원본 미디어 다운로드, 저장 큐·진행률·계정별 목록.
- X 이미지 작가·원본 찾기와 영상 장면 검색. 외부 전송 확인 및 독립 검색 세션을 사용하며, 사람 확인은 직접 진행해야 합니다.
- Pixiv 탐색·프리뷰·읽기 도움말, Pinterest 프리뷰·추가 로드·계정 보드.
- YouTube·SOOP 시청·녹화·보관, CHZZK 채팅·플레이어·다시보기, Hitomi 앨범 연결·중복 검토·다운로드 상태 관련 현재 구현.

앞선 배포 시도의 소스 폴더 오인, Windows 줄바꿈 변환 및 PowerShell 5·7 경로 정렬 차이를 수정했습니다. 빌드·패키징·검증의 PowerShell 엔진을 통일하며, 파일 해시·민감 파일·링크·업데이트 서명 검사는 유지합니다. 실패 시 지정된 완성 패키지와 증명 파일만 보존합니다.

## 검증 범위

사용자 요청에 따라 추가 CI 테스트나 수동 공개 승인 대기 없이 빌드·서명·패키지 생성 후 공개합니다.

- 앞서 전체 프론트엔드 307파일·4,621테스트, 타입 검사, 프론트엔드 빌드가 통과했습니다. 배포 합성 검사 65개와 관련 테스트 12개도 통과했습니다. 이번 버전에서 전체 테스트를 재실행한 것은 아닙니다.
- 기존 Rust 형식 검사 불일치가 남아 있으며 전체 Rust 테스트·clippy 통과를 주장하지 않습니다.
- 실제 피드 이미지·영상 검색 결과의 최종 화면 검증, 일부 계정·외부 미디어·빈 PC 경로는 보류 중입니다. 사람 확인·세션 만료·사이트 변경으로 추가 조작이 필요할 수 있습니다.
- 검색 후보는 원작자 확정 판정이 아니며, 광고 완전 차단이나 모든 콘텐츠에 대한 무영향을 보장하지 않습니다.
- 도구 소스·라이선스 고지와 CHZZK 원본 자산 권리의 별도 배포 검토는 미완료입니다. 빌드·서명 검증으로 대체하지 않습니다.

## 업데이트

설치형과 2.1.1 이상 무설치판은 앱 내부 업데이트를 지원합니다. 2.1.0 이하 무설치판은 새 ZIP을 새 폴더에 풀어 한 번 수동 교체해 주세요.

Windows Authenticode 서명은 없어 SmartScreen 안내가 나올 수 있습니다. 업데이트 파일은 기존 Atsumi 업데이트 키로 검증합니다. 기존 릴리즈와 실패한 태그는 보존합니다.
