# Atsumi v1.6.0

- 다운로드 판본 검토에서 페이지 선택 병합과 여러 앨범의 포함 관계 일괄 검토를 개선했습니다.
- 완료 앨범을 직접 골라 대조하는 흐름과 병합 이후의 검토·해시 캐시 처리를 정리했습니다.
- Explore의 앨범 제외 및 한글 검색 처리와 미리보기 갱신을 개선했습니다.
- 공통 앱 관리와 Hitomi 상태를 분리하고, 모드별 메뉴와 Danbooru API 경계를 정리했습니다.
- 모드 전환 후 탐색 결과·작업 구독 유지, 설정 저장 큐와 종료 확인의 회귀 테스트를 추가했습니다.

CHZZK 기능은 아직 포함하지 않습니다. 기존 사용자 데이터와 다운로드 경로를 유지합니다.

Windows 게시자 서명은 없는 배포입니다. 앱 내부 업데이트는 기존 Atsumi 업데이트 키로 서명을 검증합니다.
