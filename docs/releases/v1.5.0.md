# Atsumi v1.5.0

- 작가 폴더를 열지 않아도 미리보기와 태그를 미리 준비합니다.
- 태그와 썸네일을 저장해 앱을 다시 실행할 때 재사용합니다. 기존 항목은 처음 한 번 캐시를 채웁니다.
- 작가 폴더 미리보기를 가로로 펼치고, 작품이 하나인 경우에도 호버 효과를 표시합니다.
- 앨범 대표 페이지를 자동으로 고르거나 직접 지정할 수 있습니다. 다운로드 완료 후 필요한 미리보기를 갱신합니다.
- 제외 작품 폴더를 별도로 관리하고, 복원과 이동 중단 복구를 보강했습니다.
- Auto Find 페이지 이동, 랜덤 열기, 플로팅 상세 미리보기와 중복 검토 동작을 개선했습니다.
- 설정 설명을 간결하게 정리하고 저장된 썸네일을 디스크 캐시 사용량에 포함합니다.

Windows 게시자 서명(Authenticode)은 없는 배포입니다. 앱 내 업데이트는 기존 Atsumi 업데이트 키로 설치 파일을 검증합니다.
