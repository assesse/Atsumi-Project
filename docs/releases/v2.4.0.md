# Atsumi v2.4.0

합본·판본 검토와 대용량 라이브러리 반응성을 개선했습니다.

- 여러 판본의 남기기·일부만·제거 선택을 유지하고, 적용 시 활성 판본 하나만 처리하던 문제를 수정했습니다. 처리 완료 시 검토 창을 닫으며, 처리 중에는 진행 상태를 확인하면서 다른 화면을 탐색할 수 있습니다. 중간 실패 시 완료 건과 남은 선택을 구분합니다.
- 합본 중심 가로 페이지 비교, 순서가 다른 페이지의 대응 표시, Ctrl·Shift 선택 유지, 창 크기 기억을 개선했습니다.
- 작은 본문·상태 글자를 최소 13px로 조정하고 공통 스크롤바와 검토 헤더를 정리했습니다.
- Hitomi 목록 가상화, 이미지 분석 처리와 백그라운드 작업 예산, 다운로드 남은 시간 표시를 개선했습니다.
- CHZZK 녹화 중 저장 공간 관리, X 미디어 검색·결과 연결 및 다운로드 동작의 기존 통합 수정도 포함합니다.

검증: 프런트엔드 325개 파일·5,125건, 타입 검사와 프로덕션 빌드 통과. 네이티브 테스트 2,449건 통과(외부 환경 등이 필요한 93건 제외), 배포 파일 검증 65건 통과, 비교 화면의 1920×1080·1280×720·736×900 격리 브라우저 검사 26건 통과. 실제 앱에서 판본 모드 전환과 헤더 표시를 확인했으며 검증을 위해 실제 앨범을 제거하거나 병합하지 않았습니다.

현재 제한: 여러 판본의 선택 페이지를 동시에 병합하면 뒤 작업의 페이지 근거가 달라질 수 있어, 페이지 병합은 한 번에 한 판본만 허용합니다. 여러 판본의 남기기·제거는 함께 적용할 수 있습니다. 실제 포인터와 Ctrl·Shift를 동시에 입력하는 검사는 데스크톱 도구의 제약으로 격리 브라우저에서 확인했습니다. 전체 저장소의 기존 rustfmt/clippy 경고와 외부 서비스별 실시간 검증 항목이 모두 해소된 릴리즈는 아닙니다.
