# Atsumi 2.4.3

- 관련 갤러리에서도 중복 후보, 중복 판정 제외, 탐색 제외, 격리 및 다운로드 처리 상태를 구분해 표시합니다. 제외된 앨범의 표지는 흐리게 표시하고 호버하면 선명해집니다.
- 1대1 판본 검토에 합본 검토와 같은 가로 비교 및 남기기·일부만·제거 구성을 적용했습니다.
- 검토 필요 목록에서 판정할 때 창을 닫지 않고 다음 항목을 이어서 보여줍니다. 적용은 순서대로 처리하고 실패한 검토와 페이지 선택을 보존합니다.
- 다운로드·후처리 중 반복 조회와 큐 집계의 부하를 줄이고, 후처리 대기와 실제 처리 상태를 구분했습니다.
- 기존 원본 파일, 중복 판정 기준 및 업데이트 서명 검증은 유지됩니다.
