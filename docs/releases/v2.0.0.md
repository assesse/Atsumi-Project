# Atsumi v2.0.0

앨범과 페이지를 다시 찾기 쉽게 만들고, 열람·다운로드·녹화 흐름을 다듬었습니다.

- 앨범·페이지 즐겨찾기와 개인 컬렉션을 추가했습니다. 열람 중 저장하고, 내 즐겨찾기에서 검색하거나 저장한 페이지로 돌아갈 수 있습니다.
- 즐겨찾기 카드 높이를 통일하고 책갈피·컬렉션 버튼을 표지 위로 옮겼습니다. 우클릭 상세보기와 키보드 열기도 지원합니다.
- 앨범 목록은 여러 언어로 된 제목 중 한글을 먼저 표시합니다. 상세보기와 툴팁에는 원제를 유지합니다.
- PAGE PREVIEW의 두 쪽 보기·읽기 방향·오버레이·UI 고정을 개선했습니다. Alt+Tab 이후 단축키 복귀와 플로팅 디테일의 구간별 스크롤 이동을 보강했습니다.
- 다운로드 큐 조회·취소와 처리 단계 표시, 탐색 위치 복원을 개선했습니다. 이미지 전달과 해시·중복 비교 처리도 보강했습니다.
- Auto Find에서 즐겨찾기 작가·그룹을 구분해 탐색하며, 기본 범위는 해당 대상의 가장 최근 보유 앨범 이후입니다.
- 판본 비교의 페이지 선택·병합과 자동 처리 근거 확인을 개선했습니다.
- CHZZK 녹화 병합·재생·화질 선택을 보강하고, 선택 가능한 SSD 임시 저장 기능을 추가했습니다.

기존 다운로드·녹화·설정은 유지합니다. 첫 실행 시 필요한 DB 업그레이드가 적용되므로, 업데이트 후 같은 데이터 폴더를 예전 앱으로 열지 마세요. 개인 즐겨찾기는 기존 작가·태그 즐겨찾기나 공개 후기와 별도로 저장됩니다.

Windows 게시자 서명은 없는 배포입니다. 앱 내부 업데이트는 기존 Atsumi 업데이트 키로 서명을 검증합니다.
