# Atsumi 2.4.8

- X 전체화면 영상의 재생바를 클릭해 원하는 시간으로 이동할 수 있습니다. 클릭 영역은 핸들 높이까지 넓혔습니다. 기존 핸들 드래그와 단축키는 유지됩니다.
- X 자동재생 영상에 마우스를 올리면 음성을 재생하고, 벗어나면 이전 음소거 상태로 돌아갑니다. 직접 선택한 음소거 설정을 우선합니다.
- X 마음에 들어요·북마크가 같은 카드 크기를 사용합니다. 미디어 위에 제목과 정보를 겹쳐 표시합니다.
- 플랫폼 선택 메뉴 밖으로 마우스를 옮기면 메뉴가 접힙니다.
- 녹화 목록의 묶음 제목을 Ctrl+클릭해 묶음 전체를 선택할 수 있으며, 다른 묶음을 펼쳐도 선택을 유지합니다.
- 문제 녹화의 일괄 재시도와 처리 단계·진행률을 표시합니다. 이미 처리 중이거나 정상 완료된 파일은 제외하고 원본을 보존합니다.
- Windows 배포 도구 버전을 고정해 설치 파일 검증과 자동 업데이트 패키지 생성을 안정화했습니다.
