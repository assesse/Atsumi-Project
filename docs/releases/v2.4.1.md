# Atsumi v2.4.1

CHZZK 녹화 후처리와 X 영상·프리뷰 동작을 개선했습니다.

- 긴 녹화본이 처리 중에도 고정 시간 제한에 걸리던 문제를 수정했습니다. 실제 처리 진행 여부로 정체를 판단하고, 원본 확인·병합·검증·저장 단계를 표시합니다.
- 마지막 짧은 녹화 조각과 이전 병합 기록의 복구를 보완했습니다. 원본을 보존하는 명시적 복구 경로에서도 파일 해시, 영상·음성 검사와 저장 결과 검증을 유지합니다.
- 녹화 목록에서 캡처 중단 이력과 저장된 구간의 재생 가능 여부를 구분합니다. 카드의 빈 곳에서도 우클릭해 파일별 재생·폴더 열기·삭제 메뉴를 사용할 수 있습니다. 삭제 확인 절차는 유지합니다.
- 녹화본의 완료 재생시간과 프로필 이미지 대체 표시를 보완했습니다. 원본 프로필 이미지가 제공되지 않으면 기본 이미지를 표시합니다.
- X 영상의 인라인 컨트롤, 전체화면 클릭·단축키, 출처·게시자 링크의 프리뷰 이동을 개선했습니다.
- X 프리뷰 탭에 프로필 사진, 이름과 게시물 첫 줄을 표시합니다.

검증 범위: 변경 관련 자동 검사와 배포용 빌드·패키지·업데이트 서명 검증을 수행합니다. 기존 녹화의 복구는 각 파일의 검증 결과에 따라 처리되며, 누락된 원본 구간을 재생성하지 않습니다. 이번 배포 요청에서는 실제 앱 화면 조작 검사를 추가로 진행하지 않았습니다.
