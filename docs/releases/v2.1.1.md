# Atsumi 2.1.1

## 다운로드

- **무설치 권장: Atsumi-Portable.zip** — 압축을 모두 풀고 Start-Atsumi.cmd 실행.
- 설치형: Atsumi-Setup.exe.
- 설정·로그인·즐겨찾기·다운로드·녹화 데이터는 유지됩니다.

## 변경 사항

- 무설치판도 앱 내부에서 서명된 ZIP을 받아 업데이트합니다. 설치 프로그램 없이 프로그램 파일만 교체하고 다시 실행합니다. 작업 중에는 보류하며, 교체 오류 시 이전 파일을 복구합니다.
- 기존 2.1.0 이하 무설치판은 최초 한 번 새 ZIP을 새 폴더에 풀어 실행해 주세요. 이후 버전부터 앱 내부 업데이트가 가능합니다. 설치형은 기존 업데이트를 그대로 사용합니다.
- CHZZK 녹화 중 같은 형식의 트랙 재설정을 오류로 처리하지 않습니다. 지원되는 영상 형식이 바뀌면 기존 파일을 마무리하고 같은 방송 아래 새 파일로 이어 저장합니다. 사용자가 중지하거나 전환이 반복적으로 실패하면 무한 재시작하지 않습니다. 전환 경계에는 짧은 누락이 생길 수 있습니다.
- 녹화 목록을 방송 ID별로 묶고 상태를 간결하게 표시합니다. 용량은 GB/MB(1,000 기준)로 표시합니다.
- 왼쪽 메뉴의 서버 상태 문구를 제거했습니다. 메뉴 경계선으로 접기/펼치기를 지원하고 프라이버시·설정은 왼쪽 아래로 이동했습니다.
- 대기 큐·작업 중 표기 및 진행 상태 배치·가독성을 개선하고 완료된 취소·격리 작업을 구분합니다.
- 작가가 없는 작품의 그룹 분류와 제외된 앨범의 근거 확인·복원·보존 판본 연결을 개선했습니다.
- 커뮤니티 및 창 크기·레이아웃 관련 수정과 회귀 검증을 포함합니다.

## 참고

Windows Authenticode 서명은 없으므로 SmartScreen 안내가 나올 수 있습니다. 앱 업데이트는 별도 Atsumi 업데이트 키로 서명을 검증합니다. 기존 데이터나 기존 릴리즈는 삭제하지 않습니다.
