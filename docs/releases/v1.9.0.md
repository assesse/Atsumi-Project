# Atsumi v1.9.0

- CHZZK 라이브 진입을 통합했습니다. 즐겨찾기와 자동 녹화 예약 채널을 함께 표시하며, 이미 녹화 중인 방송도 같은 수신기를 재사용해 일반·마도 모드에서 시청합니다.
- 즐겨찾기를 주황색 강조와 채널 프로필·이름이 결합된 2열 배너로 표시합니다. 공개 프로필은 캐시하며, 개인정보 보호 모드에서는 숨깁니다.
- 배속과 최신 지점 따라잡기를 하나의 배속 메뉴로 통합했습니다. 마도 모드에서도 방송별 기본 볼륨 UI로 소리를 조절합니다.
- 스크린샷 버튼과 S 키는 확인창 없이 촬영합니다. 클릭한 순간의 프레임을 먼저 확보한 뒤 별도 저장 대기열에서 PNG로 저장하며, 작은 완료·실패 알림을 표시합니다.
- 녹화 중단 원인 진단, 원본 수신·저장 상태, 채널 프로필 복구 및 녹화 보관함 처리를 보강했습니다.
- 초기 실행의 준비 작업과 로딩 순서를 정리하고 개발 실행기의 복구·오류 기록을 개선했습니다.

기존 다운로드·녹화·설정은 유지합니다. 스크린샷은 설정된 다운로드 폴더의 `CHZZK/Screenshots`에 저장합니다. PNG 인코딩·디스크 저장이 끝나는 시간은 해상도와 저장 장치에 따라 달라질 수 있습니다.

Windows 게시자 서명은 없는 배포입니다. 앱 내부 업데이트는 기존 Atsumi 업데이트 키로 서명을 검증합니다.
