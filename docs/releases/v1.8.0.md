# Atsumi v1.8.0

- Hitomi 다운로드의 수신·이미지 처리·중복 판정 작업을 분리하고, 앨범 내 페이지 병렬 처리와 적응형 요청 조절을 개선했습니다.
- CHZZK 자동 녹화를 유지하면서 같은 수신기로 실시간 시청할 수 있습니다. 탭을 바꾸어도 재생·소리·PiP를 유지하고 채팅 팝업을 지원합니다.
- 녹화 중 구간 병합과 앱 내 다시보기를 통합하고, 방송 종료 사유·채널 프로필·채팅 저장 상태 표시를 보강했습니다.
- 자동 녹화의 시작 실패 기록과 방송 식별, 채팅 저장 요청의 재시도 처리를 개선했습니다.
- 상세보기와 페이지 프리뷰에서 화면을 떠나지 않고 다른 코멘트를 읽거나 별점·한마디를 남길 수 있습니다.

기존 사용자 데이터와 다운로드 경로를 유지합니다. 이 버전은 시작 속도 최적화 작업 전의 기능 변경을 보존한 릴리즈이며, 2초 이내 시작을 보장하는 버전은 아닙니다.

Windows 게시자 서명은 없는 배포입니다. 앱 내부 업데이트는 기존 Atsumi 업데이트 키로 서명을 검증합니다.
