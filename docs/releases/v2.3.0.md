# Atsumi 2.3.0

## 다운로드

- 무설치 권장: **Atsumi-Portable.zip** — 압축을 모두 풀고 Start-Atsumi.cmd 실행.
- 설치형: **Atsumi-Setup.exe**.
- 기존 설정·로그인 프로필·다운로드·녹화 데이터를 초기화하지 않습니다.

## 이번 버전에 포함된 변경

- X 공식 웹 기반 피드와 별도 다중 탭 프리뷰, 저장된 계정 전환, 마음에 들어요·북마크·로컬 저장소 탐색을 추가했습니다.
- X 게시물과 로드된 답글 보관, 미디어 원본 다운로드, 저장 큐·진행률·계정별 보관 목록을 추가하고 메뉴·포커스·이미지 이동 처리를 보완했습니다.
- X 이미지의 작가·원본 찾기와 영상의 현재 장면 검색을 연결했습니다. 외부 전송 확인과 검색 서비스별 독립 세션을 사용하며, 사람 확인이 필요하면 직접 진행해야 합니다.
- Pixiv 탐색·프리뷰·메타데이터 읽기 도움말과 Pinterest 프리뷰·추가 로드·로그인 계정의 보드 탐색을 확장했습니다.
- YouTube·SOOP 시청, 녹화·미디어 보관과 CHZZK 채팅·플레이어·다시보기 관련 현재 구현을 포함합니다.
- Hitomi의 검증된 앨범 번호 변경 연결, 중복 수동 검토 필터와 다운로드 상태 처리를 보완했습니다.
- 배포 입력·결과 해시를 기록하는 빌드 기록과 포터블 패키지 검증을 추가했습니다.

## 검증 범위와 알려진 제한

이 릴리즈는 현재 소스를 기준으로 배포합니다. 모든 기능의 실제 화면 검증이 끝났다는 의미는 아닙니다.

- 타입 검사는 통과했지만 전체 자동 검증은 통과 상태가 아닙니다. 기존 CSP 고정 목록 테스트가 새 X 로컬 미디어·보관 프로토콜과 Pixiv 동봉 사전 경로를 반영하지 않아 실패했고, 기존 소스의 공백 검사 경고도 남아 있습니다. 이번 배포 요청에서는 제품 코드나 테스트 기대값을 변경하지 않았습니다.
- X 검색은 테스트 자료로 Google Lens·SauceNAO 실제 결과 수신을 확인했습니다. 실제 피드의 승인된 이미지·영상 장면을 전송해 앱 안의 결과까지 확인하는 최종 검증은 사용자 요청으로 보류 중입니다.
- 검색 서비스의 사람 확인, 세션 만료, 요청 제한 및 웹사이트 변경에 따라 검색이 중단되거나 추가 조작이 필요할 수 있습니다. 검색 후보는 원작자나 원본의 확정 판정이 아닙니다.
- 일부 실사용 화면·계정·외부 미디어 경로의 검증은 남아 있습니다. 광고 필터가 모든 광고를 차단하거나 일반 콘텐츠에 전혀 영향을 주지 않는다고 보장하지 않습니다.
- 도구 소스·라이선스 고지 및 CHZZK 원본 자산 권리의 별도 배포 점검, 빈 PC 환경 검증은 미완료 항목으로 남아 있습니다.

## 업데이트 안내

설치형과 2.1.1 이상 무설치판은 앱 내부 업데이트를 지원합니다. 2.1.0 이하 무설치판은 새 ZIP을 새 폴더에 풀어 한 번 수동으로 교체해 주세요.

Windows Authenticode 서명은 없어 SmartScreen 안내가 나올 수 있습니다. 업데이트 파일은 기존 Atsumi 업데이트 키로 서명을 검증합니다. 기존 공개 릴리즈는 덮어쓰거나 삭제하지 않습니다.
