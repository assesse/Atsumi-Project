# Atsumi v1.7.0

- CHZZK 시청·원본 녹화·채팅 저장과 녹화본 재생, 마도 다중 시청을 추가했습니다.
- 자동녹화 수신 화면의 초기화와 시작 실패 안내를 개선했습니다. 수동 중지한 방송은 자동으로 다시 녹화하지 않습니다.
- 방송을 열기 전에도 저장된 CHZZK 로그인 상태를 확인합니다. 수동 상태 확인의 즉시 갱신·진행 표시·실패 안내를 개선했습니다.
- 작품 후기·별점·추천을 위한 커뮤니티와 상세 화면의 후기 작성 진입점을 추가했습니다.
- Windows 시작 시 자동 실행 설정, 여러 참여 작가 표시와 Windows 입력 멈춤 문제를 개선했습니다.

기존 사용자 데이터와 다운로드 경로를 유지합니다. QR 로그인 유지 기간은 NAVER가 발급하는 세션 정책을 따릅니다. 자동녹화를 나중에 별도 시청 화면으로 전환하면 추가 수신이 발생할 수 있습니다.

Windows 게시자 서명은 없는 배포입니다. 앱 내부 업데이트는 기존 Atsumi 업데이트 키로 서명을 검증합니다.
