# Atsumi 2.2.1

## 다운로드

- **무설치 권장: Atsumi-Portable.zip** — 압축을 모두 풀고 Start-Atsumi.cmd 실행.
- 설치형: Atsumi-Setup.exe.
- 기존 설정·로그인·즐겨찾기·다운로드·녹화 데이터는 유지됩니다.

## CHZZK 시청과 다시보기

- 네이버 보안 인증 후 HTTP 이동이 막혀 로그인이 진행되지 않던 경로를 HTTPS로 연결하도록 수정했습니다.
- 라이브 광고 감지·공식 플레이어 연결과 조작부 표시를 보완했습니다. 서비스 변경이나 모든 광고의 차단을 보장하지는 않습니다.
- 방송 조작 패널을 하단 손잡이로 열고 닫거나 끌어올릴 수 있도록 정리했습니다. 시청하지 않을 때는 안내를 표시하고, 도움말과 즐겨찾기 정렬도 개선했습니다.
- 전체화면의 채팅 표시, 팝업·클립 창, 최소화 중 소리와 오버레이 영역 처리를 보완했습니다.
- 스크린샷 보관함을 추가하고 촬영 직후 미리보기와 취소 기능을 제공하며, 녹화 목록과 유사한 선택 흐름을 적용했습니다.
- 녹화 재생이 끝나면 중앙에 다시보기 버튼을 표시합니다. 기존 재생 조작부는 유지합니다.
- 녹화 묶음의 펼침·접힘 상태를 저장합니다. 모두 접은 상태도 탭 이동과 앱 재실행 후 유지합니다.
- 녹화 채팅의 후원·미션 표현, 사용자 정보 표시 및 시간축 안내를 보완했습니다.

## 탐색과 설정

- Danbooru의 검색·이미지 연결 경로를 보완하고 인기순의 일간·주간·월간·전체 기간 선택을 추가했습니다.
- Hitomi 페이지 프리뷰에서 인접 원본을 미리 준비하도록 개선했습니다.
- 미확인 순차 검토는 수동 판단이 필요한 항목을 대상으로 하며 기존 문구와 UI는 유지합니다.
- 튜토리얼 다시보기, 도움말의 마우스 영역, 저장공간 분류와 SSD 작업 경로 안내를 정리했습니다.
- 이용자가 직접 보내는 오류 제보의 최근 기록 수집량을 늘리고 완료 화면을 간소화했습니다. 자동 전송하거나 공개 게시하지 않습니다.

## 업데이트 안내

설치형과 2.1.1 이상 무설치판은 앱 내부 업데이트를 지원합니다. 2.1.0 이하 무설치판은 새 ZIP을 새 폴더에 풀어 한 번 수동으로 교체해 주세요.

Windows Authenticode 서명은 없으므로 SmartScreen 안내가 나올 수 있습니다. 앱 업데이트 파일은 기존 Atsumi 업데이트 키로 서명을 검증합니다. 기존 데이터와 공개된 이전 릴리즈는 삭제하지 않습니다.
