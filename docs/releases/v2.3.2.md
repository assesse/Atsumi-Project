# Atsumi 2.3.2

## 다운로드

- 무설치 권장: **Atsumi-Portable.zip** — 압축을 모두 풀고 Start-Atsumi.cmd 실행.
- 설치형: **Atsumi-Setup.exe**.
- 기존 설정·로그인 프로필·다운로드·녹화 데이터는 초기화하지 않습니다.

## 이번 버전

2.3.0·2.3.1 배포 시도의 스크립트 문제를 수정했습니다. 정상 Rust 소스 폴더를 개인 프로필로 오인하던 검사는 검토된 파일 세 개만 정확히 허용하도록 고쳤습니다. Windows CI의 자동 줄바꿈 변환을 체크아웃 전에 끄고, 빌드 전후 입력이 다르면 변경 경로를 제한적으로 표시합니다. 입력 해시·민감 파일·링크·서명 검사는 유지합니다.

X 추가 후 오래된 테스트 기대값도 현행 구현에 맞췄습니다. 이 배포 수정에서 앱 기능과 UI는 변경하지 않았습니다. 현재 소스의 다음 기능이 함께 포함됩니다.

- X 공식 웹 기반 피드·다중 탭 프리뷰·저장된 계정 전환·마음에 들어요·북마크·로컬 저장소.
- X 게시물과 로드된 답글 보관, 원본 미디어 다운로드, 저장 큐·진행률·계정별 보관 목록.
- X 이미지 작가·원본 찾기와 영상 장면 검색. 외부 전송 확인 및 서비스별 독립 세션을 사용하며 사람 확인은 직접 진행해야 합니다.
- Pixiv 탐색·프리뷰·읽기 도움말, Pinterest 프리뷰·추가 로드·계정 보드 탐색.
- YouTube·SOOP 시청·녹화·보관, CHZZK 채팅·플레이어·다시보기, Hitomi 앨범 번호 변경 연결·중복 검토·다운로드 상태 관련 현재 구현.
- 빌드 입력·결과 해시 기록과 포터블 패키지 검증.

## 검증 범위와 남은 제한

현재 소스를 배포하는 릴리즈이며, 모든 기능의 실제 화면 검증이 끝났다는 의미는 아닙니다.

사용자의 즉시 배포 요청에 따라 추가 CI 테스트 대기 없이 빌드·서명·업데이트 패키지 생성 후 공개합니다. 기존에 완료한 검증 결과는 아래와 같으며, 미검증 항목을 통과로 처리하지 않습니다.

- 전체 프론트엔드 307파일·4,621테스트, 타입 검사, 프론트엔드 배포 빌드가 통과했습니다. 배포 안전성 합성 회귀검사 65개와 최종 버전의 관련 테스트 12개·타입 검사도 통과했습니다.
- 기존 Rust 소스의 형식 검사 불일치는 남아 있습니다. 앱 소스 변경을 제한한 이번 배포에서는 재정렬하지 않았습니다. 전체 검증 스크립트는 그 단계에서 멈췄으므로 이후 전체 Rust 테스트·clippy까지 통과한 것은 아닙니다.
- 실제 피드의 승인된 이미지·영상 장면을 외부 검색 서비스에 보내 앱 안의 결과까지 확인하는 최종 화면 검증은 사용자 요청으로 보류 중입니다.
- 사람 확인, 세션 만료, 요청 제한과 웹사이트 변경으로 검색에 추가 조작이 필요할 수 있습니다. 검색 후보는 원작자·원본의 확정 판정이 아닙니다.
- 일부 실사용 화면·계정·외부 미디어 경로, 빈 PC 환경 검증이 남아 있습니다. 광고 필터의 완전 차단이나 모든 일반 콘텐츠에 대한 무영향을 보장하지 않습니다.
- 도구 소스·라이선스 고지와 CHZZK 원본 자산 권리의 별도 배포 검토는 미완료입니다. 빌드와 서명 검증이 이 검토를 대신하지 않습니다.

## 업데이트

설치형과 2.1.1 이상 무설치판은 앱 내부 업데이트를 지원합니다. 2.1.0 이하 무설치판은 새 ZIP을 새 폴더에 풀어 한 번 수동 교체해 주세요.

Windows Authenticode 서명은 없어 SmartScreen 안내가 나올 수 있습니다. 업데이트 파일은 기존 Atsumi 업데이트 키로 검증합니다. 기존 공개 릴리즈와 실패한 태그는 덮어쓰거나 삭제하지 않습니다.
