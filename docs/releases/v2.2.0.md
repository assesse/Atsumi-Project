# Atsumi 2.2.0

## 다운로드

- **무설치 권장: Atsumi-Portable.zip** — 압축을 모두 풀고 Start-Atsumi.cmd 실행.
- 설치형: Atsumi-Setup.exe.
- 설정·로그인·즐겨찾기·다운로드·녹화 데이터는 유지됩니다.

## 녹화와 다시보기

- 장시간 녹화의 최종 병합 및 다시보기 경로 검증을 보완했습니다.
- 최종 병합과 전체 영상·음성 검증이 끝나면 원본 조각·구간 병합본과 추적 가능한 실패 임시 파일을 자동 정리합니다. 완성본·채팅·시청자 기록·프로필·검증 기록은 남깁니다. 검증 실패나 사용 중·변경된 파일은 무리하게 삭제하지 않습니다.
- 녹화 목록의 방송별 묶음·상태 표시를 정리하고 Ctrl/Shift 다중 선택을 앨범 카드와 같은 흐름으로 개선했습니다. 이미 없는 파일 때문에 목록 삭제가 막히는 경우도 보완했습니다.
- 영상 형식 전환·방송 종료 판별·저장 상태 처리를 보완했습니다.

## 라이브 시청

- 라이브의 즐겨찾기와 자동 녹화 예약을 통합하고 채널별 방송·예약 상태를 표시합니다.
- 방송 추가·선택 보기·구성 변경과 방송/채팅 개별 크기 조절을 개선했습니다. 좁은 창과 여러 방송을 함께 보는 배치를 보완했습니다.
- 로그인 세션 및 로그인 창 처리, 플레이어 조작부와 채널 정보 표시, 커서·스크롤 동작을 보완했습니다.

## 탐색과 사용성

- Danbooru 검색 정렬·기간 입력과 상세 조건 표시, 검색 결과 유지 동작을 수정했습니다.
- 작가별 폴더를 별도 플로팅 창으로 열도록 개선하고 카드 배치·미리보기·태그 잘림을 보완했습니다.
- 신규 작품 갱신의 진행·취소 흐름, 탐색 탭, 진행 상태 표시와 튜토리얼을 정리했습니다.
- 왼쪽 메뉴에서 설명과 최근 진단 기록을 확인한 뒤 직접 전송하는 비공개 오류 제보 기능을 추가했습니다. 자동 전송하지 않습니다.

## 업데이트 안내

설치형과 2.1.1 이상 무설치판은 앱 내부 업데이트를 지원합니다. 2.1.0 이하 무설치판은 새 ZIP을 새 폴더에 풀어 한 번 수동으로 교체해 주세요.

Windows Authenticode 서명은 없으므로 SmartScreen 안내가 나올 수 있습니다. 앱 업데이트 파일은 기존 Atsumi 업데이트 키로 서명을 검증합니다. 기존 데이터와 공개된 이전 릴리즈는 삭제하지 않습니다.
